# v0.17.0: historial y feedback

La aplicación guarda por defecto las consultas en una base SQLite local y permite recuperar o borrar conversaciones. El administrador controla la activación y la retención. La API limita el acceso a loopback y exige un token inyectado por el proxy de servidor. No hay cuentas ni aislamiento multiusuario.

El guardado se encola fuera del stream y reintenta en segundo plano; los fallos se registran y aparecen en Sistema. La cola es volátil ante reinicios. El usuario puede marcar una respuesta incorrecta, decidir si incluye contexto y confirmar el envío. Una persona revisa el fallo y los datos sensibles antes de exportar a JSONL los casos revisados.
